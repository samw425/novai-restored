# Core Working Principles

**THESE RULES APPLY TO ALL PROJECTS, ALL SESSIONS, ALL WORK:**

## 1. SLOW DOWN
- Take your time with every action
- Never rush through changes
- Think before each tool call

## 2. DO THINGS CAREFULLY  
- Read files fresh from disk, never trust cached knowledge
- Verify git state before any changes
- Make ONE small change at a time

## 3. DON'T BREAK ANYTHING
- Always test locally before deployment
- Run `npm run dev` and verify in browser
- Check `git status` before building to ensure clean state

## 4. DON'T MESS ANYTHING UP
- After user rollbacks, discard uncommitted changes BEFORE building
- Never assume - always verify
- If the user warns you about something, STOP and think before your next action

## 5. ONLY MOVE FORWARD
- Every change should make things better, never worse
- If unsure whether a change will help, don't make it

## 6. IF NOT SURE, TEST FIRST
- Local verification before any deployment
- Ask user to verify before pushing to production
- Build locally and check output before deploying

## 7. DO NOT WASTE TIME AND ENERGY
- The user works hard on these projects
- Reckless mistakes cost hours of their time
- Being thorough now saves massive time later
