# Product Validation Framework
**Last Updated:** January 12, 2026

## The Three Tests Every Product Must Pass

### Test 1: Demand Proof
- Are people actively searching for this?
- Are they currently paying for alternatives?
- Can we find 10 people who say "I'd pay for this"?

### Test 2: ChatGPT-Proof
- Does it require REAL-TIME data ChatGPT can't access?
- Does it require PERSISTENT state (accounts, history)?
- Does it require INTEGRATIONS (payments, APIs, emails)?
- Does it create VISUAL OUTPUT (charts, images)?
- Does it provide AUTOMATION (scheduled, monitoring)?

### Test 3: Zero-Cost Build
- Can we use only free tiers?
- Cloudflare, Supabase, Stripe, Gemini, Resend = $0/month
- Only pay when we earn (Stripe's 2.9%)

---

## What ChatGPT CAN Do (Don't Compete Here)

❌ Text generation/rewriting (resumes, emails, copy)
❌ Code generation
❌ Q&A / explanations
❌ Brainstorming
❌ Simple analysis of pasted text

**If ChatGPT can do 90% of it, we can't charge.**

---

## What ChatGPT CAN'T Do (Opportunities)

✅ **Real-Time Data**
- Live prices (stocks, crypto, flights)
- Current search rankings
- Live website monitoring
- Real-time news aggregation

✅ **Persistent State + Accounts**
- Track changes over time
- Dashboard with history
- Saved preferences
- Progress tracking

✅ **Integrations**
- Accept payments
- Send scheduled emails
- Connect to external APIs
- Post to social media

✅ **Visual/Interactive Output**
- Generate actual images
- Interactive charts/graphs
- PDF reports
- Embeddable widgets

✅ **Automation**
- Scheduled monitoring
- Alerts when conditions change
- Automatic actions

## Next Steps

1. **Pick 3- top ideas to validate**
2. **For each: Find 10 people in target audience**
3. **Ask: "Would you pay $X for this?" and "What do you use now?"**
4. **If 3+ say yes per idea, we have a winner**

---

## Validation Methods (Free)

- **Reddit:** Post in relevant subreddits asking about pain points
- **Twitter/X:** Poll followers or target audience
- **Cold Email:** Find 20 potential customers, pitch concept
- **Landing Page Test:** Simple page with email capture, run $20 in ads
- **Competitor Research:** Are paid alternatives making money?
